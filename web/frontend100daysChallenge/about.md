Stop being afraid of lengthy class names
You don't need to memorize class names. Name them according to what the element does.
Purpose     ->	Class name
Main        ->       navigation	navbar
Hero section    ->	hero
Hero heading	->    hero-title
Hero button     ->	hero-btn
Feature container       ->  	features
Individual feature      ->	feature-card
Pricing section         ->	pricing
